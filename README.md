# Le Duel - version intégrée

## Lancer le projet

```bash
npm install
npm start
```

Ouvre ensuite `http://localhost:3000` dans ton navigateur.

## Notes

- Les assets de l'image cible ont été intégrés dans le dossier `assets/`.
- L'interface d'accueil, le lobby privé, le matchmaking, le jeu et la modale avatar ont été harmonisés dans le thème gamer/casual violet-orange.
- Le système d'avatar personnalisable est conservé via `avatar.js`.
- Si ton mode Images utilise les fichiers référencés dans `server.js`, remets ton dossier `images/` d'origine à la racine du projet.
